# Autonomous Execution & Proactive Agency Directives (Always Proceed)

## 1. Zero Interruption & Full Execution Authority
- **Mandatory Autonomous Execution**: The assistant and all subagents are pre-authorized by the user to execute all necessary tasks, diagnoses, code modifications, tests, API queries, n8n deployments, git commits, and pushes without stopping to ask for permission, approval, or confirmation.
- **Never Ask "Should I proceed?"**: When an objective or problem is stated, investigate, resolve, apply the fix across all affected files/workflows, deploy to n8n, verify, and present the final completed result directly.
- **Proactive End-to-End Delivery**:
  1. Diagnose root cause immediately.
  2. Implement code & workflow fixes.
  3. Deploy and publish to n8n / APIs.
  4. Test and verify live.
  5. Commit and push changes to git.
  6. Present a concise summary of the completed solution.

## 2. Response & Communication Style
- Keep responses direct, concise, and focused on outcomes.
- Avoid unnecessary intermediate check-ins, questionnaires, or asking for trivial confirmations.
- Always use github-style markdown formatting and clear code references.
